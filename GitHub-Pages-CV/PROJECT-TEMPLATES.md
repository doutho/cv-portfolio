# Project case-study templates

Replace prompts with real details. For team projects, explain your own contribution. Use only technologies you actually used and results you measured.

## Machine learning project

**Project title:**

**Context and dates:** Course, personal, research, or team project; when it took place.

**Problem:** What did you try to predict or understand, and why did it matter?

**Data:** Source, size, relevant preprocessing, and any access restrictions.

**Approach:** Baseline, model, tools, and why you chose them.

**My contribution:** The parts you personally designed, implemented, tested, or analyzed.

**Evaluation:** Training/validation/test setup, appropriate metrics, comparison with the baseline, and limitations. Insert numbers only when verified.

**Outcome and learning:** What worked, what did not, and what you would change.

**Links:** Repository / report / demonstration.

**CV bullet draft:** Implemented [method] in [tools] for [problem], evaluated using [validation approach], with [measured outcome or concrete deliverable].
